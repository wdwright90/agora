# Agora

Agora is a project being redesigned from an existing proof of concept, with Rust and Python packages planned. Product scope and component boundaries are still to be defined.

Start with the [documentation index](docs/index.md) and [contribution workflow](CONTRIBUTING.md).

The previous implementation is preserved separately as `agora-poc`. It is reference material, not the specification for this repository. Record explicit decisions before porting its functionality.

This repository currently contains documentation scaffolding only. No application build or test commands are available yet.
